# کیت ریلزهای کامرسی

پروژه‌ی Remotion برای ساخت ریلزهای سه‌بعدی خمیری کامرسی. **هر ویدیو فقط یک فایل JSON است** (`episodes/epNN.json`). مدل‌ها، آیکون‌ها، موزیک، افکت‌ها، تم‌ها، زیرنویس و اوترو همه آماده‌اند.

- **KIT.md**: کاتالوگ همه‌ی مدل‌ها (۱۰۳)، آیکون‌ها (۱۱۳)، صداها (۷۱ صدا × ۴ نسخه)، موزیک‌ها و تم‌ها.
- **INSTRUCTIONS.md**: دستورالعمل کامل برای هر مدل زبانی (DeepSeek، Gemini، GPT…). این فایل و KIT.md را به مدل بده، موضوع را بگو، JSON بگیر.

## یک‌بار نصب

1. [Node.js](https://nodejs.org) نسخه‌ی ۲۰ یا بالاتر (LTS) رو نصب کنید.
2. پوشه رو از حالت فشرده دربیارید و داخلش ترمینال باز کنید.
3. `npm install`

## ساختن یک ویدیوی جدید

1. **INSTRUCTIONS.md** و **KIT.md** رو به مدل بدید و بنویسید: «یه ریلز درباره‌ی ... بساز، id: ep10».
2. JSON رو در `episodes/ep10.json` ذخیره کنید.
3. `npm run check ep10` ← اگه خطا داد، متن خطا رو به همون مدل بدید تا درستش کنه.
4. `npm run say ep10` ← متن راوی (با تگ‌های حس) چاپ می‌شه. توی ElevenLabs (مدل v4، یک نسخه) بسازید و با اسم `voices/ep10/full.mp3` ذخیره کنید.
5. `npm run audio ep10` ← صدا، زمان‌بندی، موزیک و افکت‌ها.
6. `npm run studio` برای پیش‌نمایش زنده، یا `npm run render-all ep10` برای خروجی `out/ep10.mp4`.

ویدیو بدون صدا هم توی Studio با زمان‌بندی تخمینی دیده می‌شه، پس قبل از ساختن صدا می‌تونید صحنه‌ها رو چک کنید.

## گالری کیت

توی `npm run studio` ترکیب‌های `gallery-01` تا `gallery-12` همه‌ی مدل‌ها و `icons-01` تا `icons-10` همه‌ی آیکون‌ها رو با اسمشون نشون می‌دن.

## تغییر رنگ و ظاهر

- **همه‌ی ویدیوها:** رنگ‌ها در `src/kit/theme.ts` هستن. تم‌های آماده: `commercy-dark` (پیش‌فرض)، `commercy-light`، `commercy-night`، `dastres-blue`، `warm-sunset`، `mint-fresh`. تم جدید هم همون‌جا اضافه می‌شه.
- **یک ویدیو:** در JSON بنویسید `"theme": "dastres-blue"` یا فقط یک رنگ رو عوض کنید: `"theme": {"base": "commercy-dark", "accent": "#FF4D8D"}`
- **یک شیء:** `"color": "accent"` یا `"color": "#FFAA00"`
- **اوترو:** `"brand": {"name": "دسترس", "tagline": "...", "cta": "...", "site": "dastres.net"}`
- **موزیک:** `"music": "calm"` (curious، calm، energetic، tension، epic، happy، mystery، festive، none)

## دستورها

```
npm run check [epNN]        # بررسی JSONها و توضیح خطاها به فارسی
npm run say epNN            # متن راوی برای ElevenLabs
npm run audio [epNN]        # آماده‌سازی صدا، موزیک و افکت‌ها
npm run render-all [epNN]   # رندر
npm run all                 # همه‌ی مراحل برای همه‌ی ویدیوها
npm run studio              # پیش‌نمایش زنده
npm run kit-doc             # بازسازی KIT.md بعد از اضافه کردن مدل/آیکون
npm run sfx-gen             # بازسازی کتابخانه‌ی صدا (پوشه‌ی sfx/)
```

### ویدیوهای ۲ تا ۸ (صداهای قبلی)

#### فایل‌های صدا

دستور `npm run all` صدای راوی همه‌ی ویدیوها رو خودش از ElevenLabs دانلود می‌کنه و توی پوشه‌ها می‌ذاره (`npm run voices` هم فقط همین کار رو انجام می‌ده).
لینک‌های دانلود امضاشده‌ان و **تا ساعت ۰۲:۳۰ بامداد ۲۳ آبان (به وقت تهران) معتبرن**. اگه بعد از اون اجرا کنید، فایل‌ها رو دستی از [فلوی ElevenLabs](https://elevenlabs.io/app/flows/ik9SjmyyIwiWxuvAcYyr) دانلود کنید و طبق جدول زیر بذارید. هر فایلی که از قبل توی پوشه باشه دوباره دانلود نمی‌شه.

هر فایل رو با همین اسم توی پوشه‌ی خودش بذارید. فرمت mp3، wav یا m4a فرقی نمی‌کنه.

| پوشه | `full.mp3` (متن کامل) | `fix.mp3` (تکه‌ی اصلاحی، اختیاری) |
|---|---|---|
| `voices/ep02/` | خوابیدن سایت موقع حراج (علی) | جمله‌ی آخر با «کَش» |
| `voices/ep03/` | صفحه‌ی وردپرس (سارا) | خط «عنوان چیه؟ مِنُ چیه؟…» |
| `voices/ep04/` | دیجی‌کالا (آیلین)، نسخه‌ی «پِیْک» | — |
| `voices/ep05/` | هکرها و ربات‌ها (علی) | — |
| `voices/ep06/` | پنج مقصر کُندی (سارا) | جمله‌ی اول با «کُندی» |
| `voices/ep07/` | سبد خرید و کوکی (آیلین) | — |
| `voices/ep08/` | خلاصه‌ی نظرها با هوش مصنوعی (علی) | — |

اگه `fix.mp3` توی پوشه باشه، اسکریپت اون خط از متن کامل رو خودکار با تکه‌ی اصلاحی عوض می‌کنه. اگه نباشه، همون متن کامل استفاده می‌شه.

برای ویدیوی ۳ یک نسخه‌ی دیگه هم دانلود می‌شه: `fix-alt-minooye-site.mp3` («مِنوی سایت چیه؟»). اگه این بهتر خونده شده، اسمش رو به `fix.mp3` عوض کنید.

## اگه مشکلی پیش اومد

- **دانلود Chrome در رندر اول خطا داد:** Remotion بار اول یک Chrome مخصوص دانلود می‌کنه. اگه دانلود نشد، از Chrome نصب‌شده روی سیستم استفاده کنید:
  ```
  $env:REMOTION_CHROME="C:\Program Files\Google\Chrome\Application\chrome.exe"
  npm run render-all
  ```
- **خطای گرافیکی یا صفحه‌ی سیاه:** رندر به‌طور پیش‌فرض از کارت گرافیک استفاده می‌کنه. اگه مشکل داشت، با پردازنده رندر بگیرید (کندتره):
  ```
  $env:GL="swangle"
  npm run render-all
  ```
- **زیرنویس یا صحنه‌ها با صدا هماهنگ نیستن:** اسکریپت جمله‌ها رو از روی مکث‌های راوی پیدا می‌کنه. اگه جایی جابه‌جا شده بود، زمان‌ها رو در `public/epNN/timings.json` دستی اصلاح کنید و فقط `npm run render-all -- epNN` رو بزنید.

## ساختار پروژه

- `episodes/epNN.json`: هر ویدیو. هر فایل جدیدی اینجا بذارید خودکار یک ترکیب در Studio می‌شه.
- `src/kit/theme.ts`: تم‌ها و رنگ‌ها.
- `src/kit/models2.tsx` و `src/clay/models.tsx`: مدل‌های سه‌بعدی.
- `src/kit/icons2.tsx` و `src/clay/icons.tsx`: آیکون‌ها.
- `src/clay/Episode.tsx`: موتور صحنه (دوربین، مسیرها، زیرنویس، اوترو).
- `scripts/audio.mjs`: صدا، موزیک (حال‌وهواها) و افکت‌ها. `sfx/`: کتابخانه‌ی صدا.
- `scripts/validate.mjs`: چک‌کننده. `scripts/kit-doc.mjs`: سازنده‌ی KIT.md.
